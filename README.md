# Cursus Network Automation

## Doel & evaluatie (wat te verwachten)

* We leren **Python** vanaf nul, met focus op **systeem- en netwerk-automatisatie**.
* **Route van de reeks**

  1. **Python-basics**:

     * Werken met **terminal**, **Python/VS Code**, **venv**, **pip**
     * **print/input**, **variabelen & types** (primitief + collecties), **type-check & casting**
     * **operatoren** (rekenen, vergelijken, logisch, lidmaatschap)
     * **controle-structuren** (`if/elif/else`) en **loops** (`for`, `while`)
     * **bestandspaden & file-IO** met `pathlib` (lezen/schrijven)
  2. **Basic automatisatie** : mappen/files, CSV/JSON/YAML, regex, subprocess, **scheduling** (cron/Task Scheduler), “veilig opnieuw draaien”.
  3. **Ansible**: inventories, modules, templating, **Python → Ansible** (triggeren).
  4. Terraform**: concepten + mini-demo.
* **Evaluatie**: **60%** oefeningen/toetsen in/na de les, **40%** examen.
* **Afspraken**:

  * **Wees op tijd**; sommige **toetsen** zijn **aan het begin** van de les.
  * **Dien taken en toetsen tijdig in**.


## 📂 Structuur van dit project
Deze repository is opgebouwd met een duidelijke scheiding tussen theorie en praktijk.
```
.
├── theorie/        # Alle theoretische uitleg per hoofdstuk
├── docs/           # kom hier niet aan, dit is om de oefeningen weer te geven
├── labos/          # Praktijkoefeningen en opdrachten
├── oefeningen/     # Bijkomende oefeningen
└── README.md       # Dit document
```

Het is belangrijk dat je de basis van Python onder de knie krijgt. Oefen deze daarom goed in via de basisoefeningen.
